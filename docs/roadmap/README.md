# agent-office-cli 발전 방향 및 로드맵 시리즈

본 디렉터리는 `agent-office-cli` 프로젝트의 중장기 발전 방향, Antigravity CLI(`agy.exe`) 활용 전략, 기능 고도화 백로그 및 의사결정 이력을 기록하는 공식 설계 문서 저장소입니다.

---

## 1. 문서 시리즈 관리 규칙 (버전 및 분할 기준)

단일 문서가 비대해져 가독성과 검색성이 떨어지는 것을 방지하기 위해 아래 기준으로 시리즈 문서를 분할·관리합니다.

1. **파일 명명 규칙**: `ROADMAP_v<번호>.md` (예: `ROADMAP_v1.md`, `ROADMAP_v2.md`)
2. **문서 분할 기준**:
   - 현재 활성 문서(`Active`)가 **350줄을 초과**하거나 완료된 마일스톤 항목이 누적되어 현행 과제 파악이 어려워진 경우
   - 아키텍처 또는 목표 방향이 크게 전환되는 **메이저 마일스톤 단위가 바뀔 때**
3. **분할 시 인수인계 절차**:
   - 기존 `vN` 문서 상단 상태를 `Archived`로 변경하고, 미완료 항목만 `v(N+1)` 문서의 이월 백로그로 옮깁니다.
   - 본 파일([README.md](./README.md))의 **시리즈 목록** 테이블에 새 버전을 등록하고 `Active`를 갱신합니다.
4. **작성 원칙**:
   - 추측성 기능이나 미확인 동작을 적지 않고, 확인된 CLI 사양(`agy.exe --help`)·코드·실행 결과에 근거해 갱신합니다.
   - 각 백로그 항목은 상태(`[ ]` / `[x]`), 우선순위(`P0`~`P2`), 대상 모듈, 완료 기준을 포함합니다.
